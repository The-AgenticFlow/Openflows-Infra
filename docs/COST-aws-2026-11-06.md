# AWS cost snapshot, 2026-11-06

What OpenFlows staging has cost so far and what to expect, taken from Cost Explorer for account `686255958454` on 2026-11-06. Production is not built, so this covers staging only. Cost Explorer lags by about a day: 2026-10-23 to 2026-11-05 are complete days and 2026-11-06 is left out. Design background is in [`docs/ARCHITECTURE-aws.md`](ARCHITECTURE-aws.md) and [`docs/ADR-0004-shared-aws-account.md`](ADR-0004-shared-aws-account.md).

## Summary

| | Usage cost (USD) | With tax (USD) |
|---|---|---|
| Spent, 2026-10-23 to 2026-11-05 | 89.95 | 107 |
| Run rate per month, current schedule | 175 | 208 |
| Design estimate, list prices | 163 | n/a |

- The run rate is about 7% above the design estimate. The likeliest gap is control plane logging, about 17 USD a month.
- A weekday costs about 6.38 USD and a weekend day about 4.56 USD, when the worker node is off.
- Tax is a separate line, about 19% of usage in both October and November.

## How OpenFlows is separated from the shared account

The account also hosts other projects, so the account total (441.44 USD for October) is not ours. Cost allocation tags are not active and this account cannot activate them, so the split is by region. OpenFlows runs only in `eu-west-1`, and every line there matches our resources: the EKS cluster, Spot nodes of the four types in the node group, the NAT instance, the admin tunnel and one ALB. If another project starts using `eu-west-1`, its cost would be counted here.

## What will move the number

| Driver | Effect |
|---|---|
| Secrets Manager entries | 0.40 USD each per month. The Manager creates one secret per user and per workspace runtime: 9 under `openflows/staging/manager/` a week before this snapshot, 13 on the day. Grows with every tenant. |
| Another worker node | About 31 USD a month. Each Coder organization runs its own provisioner pod (256 MiB request), so more organizations and tenant workspaces may not fit on one node. |
| Tenant workspaces | Not built. Each needs a disk (about 0.088 USD per GB-month) and a runtime secret. |
| Node not stopped out of hours | About 50 USD more a month. The schedule is described in [`docs/RUNBOOK-aws.md`](RUNBOOK-aws.md). |
| Production | At least about 245 USD a month before nodes and databases: control plane 73, three NAT gateways 105, three-zone ALB 18, six public IPv4 addresses 22, control plane logs 17, secrets and KMS 10. Nodes, RDS and ElastiCache are not priced because their sizing is not decided. |

## Savings, and what blocks them

- **Control plane audit logs:** would save about 15 USD a month, but changing control plane logging uses an EKS API that the AWS Organization denies.
- **Stopping staging for weeks:** saves up to about 160 USD a month by destroying and rebuilding with Terraform. Only worth it for a long idle period.

## Limits

1. The split of the shared account is by region, not by tag.
2. The 19% tax rate is read from two months of bills and may differ later.
3. Each Cost Explorer request costs 0.01 USD.
4. S3 is under one cent and not shown. The deploy role cannot list buckets because of the permissions boundary.
5. The Coder Premium license (a trial) is not on the AWS bill.

<details>
<summary>Confirm the numbers with the CLI</summary>

Cost Explorer is only served from `us-east-1`, so every `aws ce` command needs `--region us-east-1`. Save the filter as `region.json`:

```json
{"Dimensions": {"Key": "REGION", "Values": ["eu-west-1"]}}
```

```bash
# Cost and quantity per usage type for November
aws ce get-cost-and-usage --region us-east-1 \
  --time-period Start=2026-11-01,End=2026-11-06 --granularity MONTHLY \
  --metrics UnblendedCost UsageQuantity --filter file://region.json \
  --group-by Type=DIMENSION,Key=USAGE_TYPE

# Daily cost
aws ce get-cost-and-usage --region us-east-1 \
  --time-period Start=2026-10-23,End=2026-11-06 --granularity DAILY \
  --metrics UnblendedCost --filter file://region.json

# Running instances, and NAT gateways (expect none)
aws ec2 describe-instances --filters Name=instance-state-name,Values=running \
  --query 'Reservations[].Instances[].[InstanceId,InstanceType,InstanceLifecycle]' --output text
aws ec2 describe-nat-gateways --query 'NatGateways[].NatGatewayId' --output text

# Control plane log types, and the secret count
aws eks describe-cluster --name openflows-staging --query 'cluster.logging.clusterLogging'
aws secretsmanager list-secrets \
  --query 'length(SecretList[?starts_with(Name,`openflows/`)])'
```
